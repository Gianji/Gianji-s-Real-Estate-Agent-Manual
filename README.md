# PATENTINO — Accademia Immobiliare

Sito di studio indipendente per la preparazione all'esame di agente d'affari in mediazione, con lezioni di Immobiliare, Diritto ed Economia, schemi, quiz, flashcard e simulazioni.

## Pubblicazione con GitHub Pages

Il sito è statico e non necessita di server, login o database. Tutti i file pubblici sono nella radice del ramo `main`.

Per attivare GitHub Pages: **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**. L'indirizzo previsto, dopo l'attivazione e il primo deploy, è `https://gianji.github.io/Gianji-s-Real-Estate-Agent-Manual/`.

I progressi vengono conservati esclusivamente nel browser usato. Per cambiarlo, esporta e importa il backup dalla sezione Ripasso.

Il sito è uno strumento didattico indipendente: non è un sito ufficiale Tecnorete, Tecnocasa o delle Camere di Commercio. I quiz delle banche camerali sono rielaborazioni didattiche, non copie integrali degli esami.
